Phase C Backtest — The Key Finding

The Fundamental Theorem of Alpha (stated empirically): "Shrinkage is a variance-reducer, not an information-creator." Kelly sizing is an amplifier. Shrinkage is a dampener. An ML model with real IC is the engine. If the engine produces zero horsepower, the car does not move, regardless of how good the brakes are.

Kelly Activation Policy — The Two-Gate Stack

Gate A — Information
ML model produces calibrated edge with:
  • Brier < 0.05 (tightened from 0.25)
  • Jaccard ≥ 0.70 across CV folds
Sources alpha from the data.
Gate B — Variance Control
Bayesian shrinkage wraps ML edge before Kelly sees it:
  • k = 20 + 3√N pseudocount
  • k_base=20 derived from steamroller algebra
Protects tails of estimator confidence.
Both gates required. Information without variance control reproduces Phase C naive (−$477 / 55% DD). Variance control without information reproduces Phase C shrunk (−$221 / 34% DD — still negative EV on zero-IC signal).
